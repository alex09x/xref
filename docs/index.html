    Built for Reverse Engineers & Autonomous AI Agents

    Deterministic output · exact virtual addresses · zero unsafe
    c / decomp

    Structured Pseudo-C Decompiler

    Lifts x86-64 directly into if/else, while, do/while, and jump-table switch/case blocks with live System V ABI signatures, caller stack params (arg7..), (rax, rdx) tuple returns, and saturating_add folding.

    runtime + &str

    Stripped Rust Runtime & Slice Recovery

    Automatically identifies stripped rust_unwrap_failed, rust_panic_bounds_check, rust_panic_fmt, rust_once_call, and allocator helpers, and slices non-NUL &str / fmt::Arguments strings to exact byte lengths.

    layout + disp --lea

    Struct Field & Stride Reconstruction

    Recovers struct field tables (offsets, widths, read/write/lea counts, array element strides, and sub-struct callees) across register aliases, stack spills, and 1-hop callees.

    find + args

    Single-Pass Multi-Predicate Queries

    Intersect callees, referenced strings, immediate constants, struct displacements, Rust source filenames, and code size ranges in a single parallel pass across 100k+ functions.

    match (diff)

    Cross-Build Function Matching

    Relocates functions across shifted stripped builds by scoring panic locations, string literals, non-trivial immediates, struct field offsets, and 1-hop call-graph neighborhoods.

    web + json

    Zero-Latency In-Memory Web Workbench

    xref -b BIN web keeps the parsed ELF, .eh_frame table, and panic locations warm in RAM, serving interactive pseudo-C, struct layouts, and clickable call navigation in microseconds.

    Command-Line Reference

    ELF virtual addresses in hex (0x...) or decimal · XREF_BIN env supported 
    xref -b BIN stats                           # functions, code bytes, pointers, imports, panic locations
xref -b BIN refs "overflow" 0x439040        # code & data slots referencing text or address (--inline / istr)
xref -b BIN disp 0x58 --lea                 # struct field loads/stores/leas + receiving callee (--all, --stride)
xref -b BIN layout 0x2c71dd0 --callees      # reconstruct struct field offsets, widths, strides & sub-structs
xref -b BIN imm 412 --cmp                   # immediate constants (--store, --cmp, --in FN)
xref -b BIN find --disp 0x58 --lea --imm 9  # functions matching multiple predicates in one parallel pass
xref -b BIN args 0x2d37130                  # constant & symbolic arguments at every call site of a function
xref -b BIN path 0x2c5e3c0 0x2d37130        # shortest call chains between two functions
xref -b BIN tree 0x2c5e3c0 --callees        # indented caller/callee tree with ranges & panic locations
xref -b BIN match --other OLD_BIN 0x2d37130 # match shifted functions across two builds
xref -b BIN c 0x2d37130 --out ./decomp      # structured pseudo-C decompilation (alias: decomp)
xref -b BIN web --addr 127.0.0.1:7700       # launch interactive in-memory web workbench
