    Built for Reverse Engineers & Autonomous AI Agents

    Deterministic output · exact virtual addresses · zero unsafe
    c --fields

    Structured Pseudo-C & Field Sugar

    Lifts x86-64 directly into if/else, while, do/while, and jump-table switch/case blocks with System V ABI signatures, signed overflow ops, and rsi->vec_20.{ptr,len} field sugar.

    runtime + &str

    Stripped Rust Runtime & Slice Recovery

    Automatically identifies stripped rust_unwrap_failed, rust_panic_bounds_check, rust_panic_fmt, rust_once_call, and allocator helpers, and slices non-NUL &str / fmt::Arguments strings to exact byte lengths.

    layout + disp --lea

    Struct Field & Provenance Recovery

    Recovers struct field tables (offsets, widths, read/write/lea counts, array element strides, and forwarded callee parameter provenance) across register aliases, stack spills, and 1-hop callees.

    find + args

    Single-Pass Multi-Predicate Queries

    Intersect callees, referenced strings, immediate constants, struct displacements, Rust source filenames, and code size ranges in a single parallel pass across tens of thousands of functions.

    match + dump

    Cross-Build Matching & Tree Dump

    Relocates stripped functions across builds via invariant scoring, and dumps entire Rust module trees (<crate>/src/.../*.c) reconstructed from panic locations in parallel.

    slice + diff-c

    Backward Slicing & Cross-Build Diff

    xref slice isolates reaching definitions and early-exit guards leading to any target call or field; xref diff-c normalizes volatile addresses to diff pure logic across builds.

    Command-Line Reference

    Self-hosted examples on target/release/xref · XREF_BIN env supported 
    xref -b target/release/xref stats                             # functions, code bytes, pointers, imports, panic locations
xref -b target/release/xref refs "goto L_" 0xa1b50            # code & data slots referencing text or address (--inline / istr)
xref -b target/release/xref disp 0x20 --lea                   # struct field loads/stores/leas + receiving callee (--all, --stride)
xref -b target/release/xref layout 0x9e840 --reg rsi --callees # reconstruct struct field offsets, widths, strides & callees
xref -b target/release/xref imm 24 --in 0xa1b50               # immediate constants (--store, --cmp, --in FN)
xref -b target/release/xref find --src src/loops.rs --calls 0x15a8f0 # multi-predicate function search in one parallel pass
xref -b target/release/xref args 0xcafb0                      # constant & symbolic arguments at every call site of a function
xref -b target/release/xref path 0xb3180 0x15a8f0             # shortest call chains between two functions
xref -b target/release/xref tree 0xb3180 --callees            # indented caller/callee tree with ranges & panic locations
xref -b target/release/xref match --other xref.prev 0x9e840   # match shifted functions across two builds
xref -b target/release/xref diff-c --other xref.prev 0x9e840  # cross-build normalized pseudo-C diff (--fields)
xref -b target/release/xref c 0x9e840 --fields                # structured pseudo-C with struct & Vec<T> field sugar
xref -b target/release/xref slice 0xcafb0 --to fn_15a8f0      # backward program slice to target call/field/address
xref -b target/release/xref dump --out ./decomp --src src/    # parallel modular source-tree pseudo-C dump
