$Ultra blazing fast cross-references & structured pseudo-C for x86-64 ELF and Mach-O binaries.

XRef (xref) recovers function ranges from .eh_frame unwind tables (with span fallback) and runs whole-binary scans across CPU cores via rayon in memory — no multi-minute database import, no stale cache, and millisecond xrefs, layout recovery, backward slices, and typed pseudo-C on stripped Rust release binaries (shown below analyzing stripped xref itself, with 0 gotos across all 7 recorded functions).

Built for Reverse Engineers & Autonomous AI Agents

          Deterministic output · exact virtual addresses · zero unsafe
        

        

          

            
c / c --fields

            
Typed Pseudo-C, 128-bit ALU & Carry

            
Recovers immutable arg_* signatures, live-range webs (ptr_*, v_*, slot_*), 1-operand widening mul/div (u128/i128), multi-precision adc/sbb carry chains, and optional f_* offset hints.

          

          

            
runtime + &str

            
Stripped Rust Runtime & Panic Anchors

            
Recognizes stripped rust_panic_bounds_check, rust_slice_index_fail, and rust_capacity_overflow helpers, bounds unproven .rodata previews, and slices exact &str / core::panic::Location descriptors.

          

          

            
layout + disp --lea

            
Struct Displacement & Stride Tables

            
Aggregates memory displacements, access widths, read/write/lea counts, SIB array strides, and 1-hop forwarded callee parameter offsets per pointer argument register.

          

          

            
find + args

            
Single-Pass Multi-Predicate Queries

            
Intersects callees, referenced strings, immediate constants, struct displacements, Rust source paths, and byte size bounds in one parallel pass across all functions.

          

          

            
match + diff-c

            
Cross-Build Relocation & Diffing

            
Matches stripped functions across compiler builds via structural invariants and diffs normalized pseudo-C with shifted addresses, labels, and skip flags abstracted away.

          

          

            
slice + dump

            
Backward Slicing & Modular Export

            
xref slice isolates balanced statements and guards reaching an exact instruction IP, call, or panic site; xref dump groups stripped functions by panic source paths into modular .c files.

          

          
query / mcp

            
Versioned JSON & Local MCP

            
One immutable image, SHA-256 identity, typed schemas, pagination, cancellation and explicit budgets. info opens with a triage and ready-to-run next queries; every answer carries a confidence tier and a deterministic evidence ID; --compact keeps responses short. Configure a local read-only agent tool.

          
origin / callargs

            
Error Origins & Constant Arguments

            
Start from an error message: origin lists the stores of its enum tag, conversions, calls passing the tag and the guards around each, following it through copies, spills, stack objects, records and loops that read them by value. callargs finds every call passing a constant. origin · callargs.

          
deps / data

            
Build Provenance & Typed Data

            
Read the dependency manifest cargo-auditable embeds in Rust binaries and the Go module list, with toolchains and Build-ID, and typed values at any virtual address. Only what the binary embeds is reported. deps · data.

          
c / calls / table

            
Floating Point & Vtable Dispatch

            
Pseudo-C types scalar SSE/AVX f32/f64 parameters, returns and call results; an indirect call through constant vtables lists each possible target with the branch condition that selects it, and table dumps the records with their relocated pointers. table.

          
investigate / field_origin

            
Bounded Evidence Trails

            
Keep alternative call sites, CFG guards and instruction definitions visible; distinguish field addresses from loaded values. Investigations · Field origins.

          
Mach-O / --stack / --goto

            
More Inputs & Expert Views

            
Thin little-endian x86-64 Mach-O with DWARF FDEs; ARM64, universal and compact-only input remain unsupported. Explicit stack anchors and opt-in goto output.

          
live maps / memscan / resolve

            
Live Process Memory, Tied to Static Code

            
Verify the running executable, search private writable memory for known values and classify neighbouring words as code, string, heap or vtable pointers resolved to static functions. Recorded walkthrough.

          
live probe / watch --follow

            
Call Counts & Field Writers

            
Bounded perf uprobes count calls, callers and registers; DR0–DR3 watchpoints name the candidate store and value, and follow a buffer after it moves. Coverage gaps stay explicit.

          
mcp --allow-live-pid

            
Opt-in Live MCP

            
The xref_live tool is exposed only when a verified PID is pinned at startup, with strict budgets, one live call at a time and cancellation. Contract & limits.

          
field --writer-root

            
Serialized Field Search

            
Connects serialized key strings to struct field offsets with instruction witnesses and ranks candidate writers, optionally only through a returned, argument or loaded pointer. Rankings are heuristic candidates, not type proof. Field search.

          
live trace / live profile

            
Ordered Call Traces & CPU Profiles

            
Record thread-scoped call windows in program order through tracefs uprobes, with explicit stop points and limits, and sample bounded CPU profiles of one verified process. Linux x86-64; traces need privileged tracefs access, profiles depend on the kernel perf_event_paranoid policy.

          
profile / symbolize / edges

            
Offline Profiles & Stacks

            
Summarize, annotate and diff .xprof recordings, import perf.data (with bounded Intel PT decoding) or perf script text, and map saved stacks and observed call edges onto the selected executable. Offline traces.

        

      

      

        

          
Command-Line Reference

          xref.stripped commands verified against 68aa57b · ./app lines show syntax · XREF_BIN env supported
        

        
xref -b xref.stripped stats                                              # functions, code bytes, pointers, imports, panic locations
xref -b xref.stripped refs "goto L_"                                     # code & data slots referencing text or address (--inline)
xref -b xref.stripped disp 0x18 --lea --in 0x65e30                       # struct field loads/stores/leas + receiving callee (--all, --stride)
xref -b xref.stripped layout 0xa2270 --reg rsi --callees                 # aggregate struct offsets, widths, strides & 1-hop callees
xref -b xref.stripped imm 59 --cmp --in 0xc7d60                          # immediate constants (--store, --cmp, --in FN)
xref -b xref.stripped find --src src/loops.rs --calls 0x160bb0           # multi-predicate function search in one parallel pass
xref -b xref.stripped where src/image.rs --line 46                       # map Rust source file & line to stripped function ranges
xref -b xref.stripped args 0xa2270                                       # constant & symbolic arguments across all call sites
xref -b xref.stripped path 0xc7fc0 0x160bb0                              # shortest call chains between two functions
xref -b xref.stripped tree 0xd0aa0 --callers --depth 2                   # indented caller/callee tree with panic locations
xref -b xref.stripped variant 0xc7fc0 2                                  # jump-table arms & string literals for enum discriminant
xref -b xref.stripped match --other xref-v0.0.2.stripped 0xc7d60 --top 2 # relocate shifted functions across two stripped builds
xref -b xref.stripped diff-c --other xref-v0.0.2.stripped 0xd57c0        # cross-build normalized pseudo-C diff
xref -b xref.stripped c 0xc7d60 --fields                                 # structured pseudo-C with heuristic offset hints
xref -b xref.stripped slice 0xc7d60 --to fn_160bb0 --fields              # backward program slice to target call, IP, or string
xref -b xref.stripped dump --out out-loops --src src/loops.rs            # parallel modular pseudo-C export by source file
xref -b xref.stripped query '{"operation":"info"}'                      # versioned JSON with immutable image identity
xref -b xref.stripped mcp                                              # local read-only stdio MCP
xref -b xref.stripped disp 0x18 0x28 --all --stack                      # fields relative to explicit stack anchors
xref -b xref.stripped c 0xc7d60 --goto                                  # preserve residual labels and transitions
xref -b ./app live memscan --pid PID 0x4441454d4f4e5632                  # Linux: find values in a running process (also maps, resolve)
sudo xref -b ./app live probe --pid PID --callers 0x1f9f0               # Linux: bounded uprobe call counts, callers, registers
sudo xref -b ./app live watch --pid PID 0x55d1e1c3adc8                  # Linux: hardware write watch (--follow for moving buffers)
sudo xref -b ./app live trace --pid PID --start 0x1f9f0 --stop-return 0x1f9f0 --callees-of 0x1f9f0 # Linux: ordered per-thread call windows
sudo xref -b ./app live profile --pid PID --duration 10s --out app.xprof # Linux: bounded CPU sampling profile
xref -b ./app field --keys c,m,e --write --writes-all-of m,e             # serialized keys -> field layout & ranked writer candidates
xref -b ./app profile report app.xprof --by function --top 30            # summarize (also annotate, diff, import perf.data) profiles
xref -b ./app origin "number out of range"                               # code that builds an error: tag stores, conversions, guards, readers
xref -b ./app callargs 0x2c --arg rdx                                    # every call passing a constant, grouped by callee
xref -b ./app deps --filter tokio                                        # embedded cargo-auditable / Go build manifest, toolchains, Build-ID
xref -b ./app data 0x492c0b --as str                                     # typed values at a virtual address
