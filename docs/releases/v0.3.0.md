# XRef v0.3.0

**Ultra Blazing Fast native binary analysis, now with Live Linux Process
Inspection (L1–L4), opt-in MCP live tooling, and public product branding as
XRef.**

## Live Linux Process Inspection (Linux x86-64)

XRef v0.3.0 introduces native live process inspection for running Linux x86-64
targets, connecting runtime process state directly with static image analysis:

- **L1 Maps & Resolve (`xref live --pid PID maps`, `xref live --pid PID resolve`)**:
  Inspect live `/proc/PID/maps` memory layout, locate the main executable, heap,
  thread stacks, VDSO/VVAR, and dynamically loaded modules. Resolve any runtime
  virtual address to its backing file, mapped segment offset, static image VA,
  and containing function with typed demangled symbol names.
- **L2 Memory Scanner (`xref live --pid PID memscan`)**:
  Scan readable process mappings for exact ASCII strings, hex byte sequences, or
  pointer-aligned word references. Matches report containing memory region,
  protection flags, offset, and dereferenced pointers.
- **L3 Execution Probes (`xref live --pid PID probe`)**:
  Attach lightweight execution breakpoints via `ptrace(2)` to target functions or
  VAs. Capture execution hits with CPU register state (`rax`, `rdi`, `rsi`,
  `rsp`, `rip`, flags) and exact DWARF/CFI-driven caller backtraces without
  disturbing runtime execution.
- **L4 Memory Watchpoints (`xref live --pid PID watch`)**:
  Hardware-assisted and software-monitored variable watchpoints. Intercept writes
  to target memory locations, compute before/after values, and attribute stores
  to specific candidate instructions within the main executable. With `--follow`,
  re-bind watchpoints automatically when target pointers or moving buffers shift
  dynamically across allocations.
- **Opt-in MCP Live Tooling**:
  `xref_live` tool exposed via local stdio MCP server (`xref -b BIN mcp`) with
  explicit safety defaults, bounded timeouts, and strict privilege checks.
- **Interactive Walkthrough**:
  Detailed recorded walkthrough with verbatim Linux terminal sessions published
  at [https://xrefcode.com/live-walkthrough](https://xrefcode.com/live-walkthrough).

## Public Product Branding

- The public product brand is streamlined to **XRef** (previously XRef Code).
- The signature tagline **Ultra Blazing Fast** is preserved across all headers,
  documentation, and web surfaces.
- All technical identifiers remain stable: binary name `xref`, Rust crate
  `xref-code`, repository `alex09x/xref`, and website `xrefcode.com`.

## Install

```sh
cargo install xref-code --version 0.3.0 --locked
# or use prebuilt release archives / cargo-binstall:
cargo binstall xref-code --version 0.3.0 -y
# Homebrew users with an existing installation:
brew update && brew upgrade alex09x/apps/xref
```

Release archives support Linux x86-64 (glibc >= 2.34) and macOS Apple Silicon.
Live process inspection is currently supported on Linux x86-64 kernels with
`ptrace` / `/proc` access permissions. Inspected processes continue normal
execution after probes or watchpoints complete.
