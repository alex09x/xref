# XRef Code v0.2.0

**Ultra Blazing Fast native binary analysis, now with versioned JSON, local
MCP, bounded evidence trails and supported thin x86-64 Mach-O inputs.**

## Native analysis for agents

- `xref -b BIN query '<JSON>'` and `xref -b BIN mcp` share the native analysis
  engine. Responses carry schema version 1, exact image SHA-256, static VAs,
  warnings, limits and pagination. MCP runs locally over stdio for one immutable
  image, with cancellation and bounded concurrent requests.
- The JSON operation `investigate` connects string hits, references, functions, calls and a selected
  slice. Alternative functions and call sites remain explicit; a selection is
  bound to the image identity. Unknown indirect flow is not treated as absence.
- The JSON operations `call_context`, `callers` and `field_origin` expose instruction provenance,
  direct-CFG argument/guard evidence, memory access modes and bounded one-hop
  callee evidence. A field address and a loaded value remain different origins.
  CFG uncertainty, untracked origins and traversal limits are reported.

## More input and output choices

- Thin little-endian x86-64 Mach-O executables, dylibs and bundles with usable
  DWARF `__eh_frame` feed the same CLI, JSON and MCP operations. Entry offsets
  become static VAs relative to `__TEXT.vmaddr`; supported legacy/chained dyld
  linkage and exports are decoded without guessing encoded pointers.
- Mixed-CFI gaps and unsupported fixup metadata remain explicit. Partial caller
  sets cannot erase or narrow possible Mach-O RAX/RDX returns.
- `disp --stack` includes raw frame displacements and offsets from explicit
  address-taken stack anchors, normalized across proven stack-pointer changes.
- `c --goto`, `slice --goto` and `dump --goto` preserve residual transitions for
  experts inspecting large functions. Structured output remains the default.

## Install

```sh
cargo install xref-code --version 0.2.0 --locked
# or use prebuilt release archives / cargo-binstall:
cargo binstall xref-code --version 0.2.0 -y
# Homebrew users with an existing installation:
brew update && brew upgrade alex09x/apps/xref
```

Release archives support Linux x86-64 (glibc >= 2.34) and macOS Apple Silicon.
The macOS ARM64 host binary analyzes x86-64 inputs; this is not an ARM64 input
backend. ARM64 inputs, PE, fat/universal, encrypted, relocatable and
compact-unwind-only Mach-O remain unsupported. Inspected binaries are never
executed. Pseudo-C, types and layouts remain static reconstructions; use raw
ASM and provenance for critical conclusions.
